The path matches as a prefix, so the last part may be unfinished: 재정간행물/월간나라재정/2018년_ covers every folder starting with 2018년_. End the path with / to pin exactly one folder.

Each entry's 파일명 is compared against the filenames under the path. Underscores and spaces count as the same character and file extensions (.pdf, .hwp, …) are ignored on both sides.

A 파일명 ending in .zip matches a folder named like the archive instead — the zip's PDFs were registered as separate documents. Save then writes the zip's ids onto every document in that folder.

Save DB writes 게시물ID → source_document_id, 첨부파일ID → atch_file_id, 첨부순번 → atch_file_seq on every cleanly matched document. Not-found and ambiguous entries are skipped, never guessed.

Both listing formats are accepted: 재정간행물 (유형명 · 파일명 · 게시물ID · 첨부파일ID · 첨부순번) and 재정보고서 및 문서 (allDtaClsNm · dpFileNm · odtId · atchFileId · atchFileSeq). There odtId is saved as the 게시물ID and fileExt is joined back onto the name.
