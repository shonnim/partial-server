{# The Transfer pop-up: the RAG bucket's TOC on the left, what the headers table holds on the right, so the two can be compared before either transfer button writes one side into the other — "Transfer to Stored Headers ⇒" upserts the bucket TOC into the table, "⇐ Transfer to Bucket TOC" replaces the metadata JSON's TOC with the stored headers (confirmed first, since the pipeline's TOC entries are discarded). Both panes use the same row markup as the outline pop-up — title, printed page, start–end page_idx — and a row missing either index is tinted red the same way. On the Stored side, anything that disagrees with the bucket TOC is painted red at the point of disagreement: the differing characters of a title, a printed page, either page index. A stored header the TOC does not name at all is wholly red — a transform would not touch it. Each pane also has its own Edit mode (headers.js toggles .is-editing on the pane): every row's title and three numbers become inputs, and Save posts the pane's rows to that pane's own route — the bucket pane rewrites the metadata JSON, the Stored pane the headers rows. The two editors never touch each other's side.
